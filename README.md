# Bachelor's Engineering Thesis – In Progress

## Bidirectional Speech-to-Text Translation System for Polish and Turkish

<badge color="success">In Development</badge>

An ongoing engineering thesis project focused on developing a bidirectional speech translation system between Polish and Turkish.

The goal of the project is to create an application capable of recognizing spoken language, converting speech into text, and translating between Polish and Turkish in both directions.

**Expected thesis defense:** February 2027

## Requirements

- Python 3.12.x
- 16 GB RAM recommended for optimal performance

## Running the Application

### Windows

Run the following file:

```bash
run.bat
```

### Linux

First, make the script executable:

```bash
chmod +x run.sh
```

Then execute it:

```bash
./run.sh
```

## Environment Setup

On the first launch, the application automatically creates a Python virtual environment (`venv`) and installs the libraries required for the application to work.

All project dependencies are managed within this virtual environment, keeping the application isolated from the system-wide Python installation.

## Project Status

This project is currently under development as part of an engineering thesis. Its functionality, architecture, and implementation are subject to ongoing development and improvements.
